# Remote-Controls-IR-Signal-Dumps

This repository contains a collection of infrared (IR) signal dumps from various remote controls. The dumps are intended for use in DIY projects, home automation setups, or general experimentation with IR communication. All signals are recorded as raw console output and are not modified or cleaned up in any way, so you can work with the original data directly.
The project originally started because I wanted to reuse a cheap RGB LED remote control with an ESP32. The LED controller includes an IR receiver module that can easily be repurposed. By cutting the cable, three wires become accessible: red for 3.3V, black for ground, and blue for the signal. These can be connected directly to an ESP32, making it possible to integrate the remote into systems like Home Assistant. This setup works reliably and is simple to reproduce.
Since I already had the setup running, I decided to start collecting and uploading IR dumps from any remote controls I come across. This includes devices like RGB LED remotes as well as more complex systems such as the Logitech Z-5500 Digital 5.1 Speaker System remote control. The goal is simply to build a growing collection that others can use for their own projects.
Each dump in this repository is accompanied by a photo of the remote control. The images show the exact order in which the buttons were pressed, so it is easier to understand and reproduce the signals. The dumps themselves are simple copy-and-paste outputs from the console, kept exactly as recorded without additional formatting or editing.

Dieses Repository enthält eine Sammlung von Infrarot-(IR)-Signal-Dumps verschiedener Fernbedienungen. Die Dumps sind für DIY-Projekte, Home-Automation oder allgemeine Experimente mit IR-Kommunikation gedacht. Alle Signale werden als roher Konsolen-Output gespeichert und nicht bearbeitet, sodass die Daten im Originalzustand zur Verfügung stehen.
Das Projekt hat ursprünglich damit angefangen, dass ich eine günstige RGB-LED-Fernbedienung mit einem ESP32 weiterverwenden wollte. Der LED-Controller besitzt einen IR-Empfänger, der sich einfach umbauen lässt. Wenn man das Kabel freilegt, kommen drei Leitungen zum Vorschein: Rot für 3.3V, Schwarz für GND und Blau für das Signal. Diese lassen sich direkt mit einem ESP32 verbinden, wodurch die Fernbedienung beispielsweise in Home Assistant integriert werden kann. Das funktioniert zuverlässig und ist leicht nachzubauen.
Da ich das Setup sowieso bereits hatte, habe ich angefangen, alle Fernbedienungen zu dumpen, die mir in die Hände fallen. Dazu gehören einfache RGB-Fernbedienungen genauso wie komplexere Geräte, zum Beispiel die Fernbedienung des Logitech Z-5500 Digital 5.1 Speaker System. Ziel ist es, nach und nach eine Sammlung aufzubauen, die auch für andere nützlich ist.
Zu jedem Dump gibt es ein Bild der jeweiligen Fernbedienung. Auf den Bildern ist die Reihenfolge der gedrückten Tasten zu sehen, sodass man die Signale besser nachvollziehen kann. Die Dumps selbst sind einfache Copy-&-Paste-Ausgaben aus der Konsole und bleiben bewusst unverändert und unbearbeitet.
